# 大文档与扩展卡片

PDF 页数不再限制 24 页，支持 400–500 页按批处理。文件上限 512MB，但仍受设备内存、PDF 复杂度和模型上下文限制。只渲染当前 1–8 页，默认 2 页。打开文档后确认页码和压缩档，点击确认加载；检查素材后手动生成、检查与导入，再标记本批完成。每一批均由用户启动，不会后台自动调用模型。

压缩档：省流 1100px/62%、均衡 1600px/80%、清晰 2200px/92%、高保真 3000px/98%。这是发送给 AI 的页面图像压缩，不是重写原 PDF。压缩可能损失小字，先看图片预览，不能保证极限压缩后识别不受影响。PDF 默认文字和图像同时保留；DOCX 仍只提取文字，需要图表时请转 PDF。

进度保存在此浏览器，刷新后重新选择同名、同页数文件可恢复已完成范围；卡片结果仍在原历史中。不要用相同名称替换不同内容，文件句柄与素材不会跨刷新持久化。

首页齿轮提供逐条规则（启停、移除）、每批页数、文档清晰度、页面图像、来源显示、问题和答案过载阈值、重复检查。设置按浏览器及访问地址隔离，尚非跨设备同步。全局规则随生成请求发送，不包含 API Key。

每张卡可使用 source:{file,page,quote}，quote 应逐字摘录；模型定位需人工核对。未定位的卡片保留 sourceCandidates，明确是本批候选范围，不冒充精确来源。重复检查比较当前批问题和此前成功导入的问题（最近 3000 条），采用去标点精确匹配，不是语义判重；过载按字数提示，不自动删卡。

新增 JSON 类型：

```json
{"type":"occlusion","front":"识别图中部位","back":"答案","imageIndex":0,"masks":[{"x":0.2,"y":0.3,"w":0.1,"h":0.1}]}
```

模型输出 imageIndex，生成接口替换为当前图像的 data URL；手写卡片也可以直接提供 image。多个矩形构成一张卡，同时隐藏／揭示；若想单独考每个部位，JSON 分成多张。预览支持揭示，Anki 使用 Basic 模板、媒体文件和遮挡 HTML；不是 Anki 原生 Image Occlusion 笔记类型。

```json
{"type":"audio","front":"听音作答","back":"答案","audio":"data:audio/mpeg;base64,真实音频数据"}
```

音频需真实 MP3/WAV/OGG base64 数据；不含 TTS 自动配音。媒体单卡上限 12MB。遮挡和音频通过 AnkiConnect storeMediaFile 保存，导入普通 Basic 卡。TXT 导出继续只导原 basic/cloze，媒体卡请直接导入 Anki。
