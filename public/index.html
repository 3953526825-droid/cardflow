「抓全文」不通？点开看 Jina 中转怎么弄
「抓全文」会把请求发到 r.jina.ai（把网页转成纯文本）。如果手机网络到不了它（国内直连常这样），可以自己搭一个「中转」，地址填在上一栏：填一次会记在本机，刷新/重开 App 都不丢；留空 = 继续用默认 r.jina.ai。

做法一：有台能上网的电脑或服务器（Nginx）
加一条反向代理：location /jina/ { proxy_pass https://r.jina.ai/; }
然后把 https://你的域名/jina/ 填进上一栏。

做法二：Cloudflare Worker（免费，手机浏览器也能配）
新建一个 Worker，让它把「Worker 地址后面的完整网址」转给 r.jina.ai，例如：
export default { fetch(req) { const u = new URL(req.url); return fetch('https://r.jina.ai/' + u.pathname.slice(1) + u.search); } }
部署后把 Worker 地址（如 https://xxx.workers.dev/）填进上一栏。

格式要点：中转只做「前缀拼接」——App 会把「中转地址 + 目标网址」原样发过去，所以中转要把后面的完整网址转给 r.jina.ai，不要改写路径。末尾带不带 / 都可以。
